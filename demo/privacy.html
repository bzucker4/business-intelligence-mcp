Business Intelligence Copilot

Privacy Policy

Last updated: October 19, 2026

Business Intelligence Copilot is a demonstration MCP server that analyzes a fictional CSV dataset bundled with its source code. It does not currently accept user file uploads, connect to private business systems, or require an account.

Information processed

When an MCP client calls a tool, the service processes the tool name and arguments needed to run the requested analysis, and returns the result to that client. The available tools read CSV files bundled in the deployed data/ directory. The application does not create a database or intentionally save tool arguments, query text, or results as application records.

Hosting and operational logs

The service is hosted by Render. The hosting provider may process technical information such as request metadata, service logs, IP addresses, and diagnostic information under its own policies and service terms. Application and platform logging settings may change; users should not submit sensitive or confidential information to this sample-data service.

Render privacy information: https://render.com/privacy.

Data scope and security

The public service is unauthenticated and is intended only for the bundled fictional sample data. Do not place private, personal, or confidential business data in the deployed data directory. The service does not access Claude memory, chat history, conversation summaries, or user-uploaded files.

Retention and deletion

The application does not provide user accounts, uploads, or an application database, so it has no user dataset deletion workflow. Operational logs controlled by the hosting provider may have separate retention periods under the provider's policies. Contact the project maintainer through the support page for questions about this policy.

Changes and contact

This policy may be updated when the service changes. For questions or privacy concerns, use the support channel listed at /support. Do not post personal, confidential, or sensitive information in a public issue.
