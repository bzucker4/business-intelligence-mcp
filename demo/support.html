Business Intelligence Copilot

Support and security reporting

Business Intelligence Copilot is a sample-data demonstration. It does not accept uploads or analyze private business systems.

Product support

For reproducible bugs, questions, or feature requests, use the project's GitHub issue tracker. Include the tool name, a description of what you expected, and the non-sensitive error message. Do not include secrets, personal information, or customer data.

Security concerns

For a suspected vulnerability, use GitHub's private vulnerability reporting flow if it is enabled for this repository. If it is unavailable, do not publish exploit details or sensitive information in a public issue; use the maintainer's GitHub profile to find an available private contact route.

Service limitations

  • The service currently analyzes only the bundled fictional CSV.
  • The public endpoint is unauthenticated and is not intended for private data.
  • Outlier flags are statistical review candidates, not automatic determinations of error.
